# Acknowledgements

PSAMR began as the `co2-eos` development branch of a fork of CAMR (https://github.com/AMReX-Fluids/CAMR), the compressible-flow AMReX code by the AMReX-Fluids developers. The block-structured hydrodynamics, build system and much of the infrastructure derive from that code, and upstream CAMR changes continue to be merged.
